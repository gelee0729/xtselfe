### Installation

`xtselfe` is available from [SSC](https://ideas.repec.org/c/boc/bocode/s459713.html) and can be installed in Stata by typing `ssc install xtselfe` in the Stata Command window.


### References

For details on the Stata implementation of `xtselfe`, see:

  1. Han, C. and G. Lee, 2026, Bias Correction for the Within-Group Estimator for Panel Data Sample-Selection Models, *The Stata Journal*, Forthcoming. ([Accepted author manuscript](https://drive.google.com/file/d/1Mim-5-jNMAnTD6HF1C-xKxJrV-9t_oJk/view?usp=sharing))

For the original methodological contribution, see:

  2. Han, C. and G. Lee, 2022, Bias Correction for Within-Group Estimation of Panel Data Models with Fixed Effects and Sample Selection, *Economics Letters*, 220, 110882. ([DOI](https://doi.org/10.1016/j.econlet.2022.110882))
